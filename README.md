# 立体书样机展示 · Pop-up Book Mockup

上传画作，自动拆分为 **背景 / 角色 / 小物件** 三层纸艺元素，并以 3D 立体书形式展示景深效果。支持逐层单独查看、爆炸视图与多作品管理。

**在线预览**：开启 GitHub Pages 后访问 `https://<你的用户名>.github.io/<仓库名>/`

## 功能

- 🖼 拖拽 / 点击上传图片（支持多张）
- ✂️ 纯前端自动分层：背景（区域生长抠图）· 角色（显著主体检测）· 小物件（其余前景连通域）
- 📖 Three.js 3D 立体书：硬壳封面、纸页、三层纸艺切片（背景平贴 / 角色立起 36° / 小物件近景 40°）
- 🎛 元素单独显示：完整画面 / 背景层 / 角色层 / 小物件层 一键切换
- 💥 分层视图（爆炸图）便于检查拆分结果
- 🔄 自动旋转、视角复位、重新拆分
- 🦊 内置示例画作（程序化生成的小狐狸森林）

## 本地运行

无需构建，任意静态服务器即可：

```bash
cd popup-book
python -m http.server 8765
# 打开 http://localhost:8765
```

或直接双击 `index.html`（需联网加载 Three.js CDN）。

## 技术说明

- 纯前端实现，无后端、无 AI 接口，图片不上传服务器
- 分层为启发式算法（颜色连通域），对背景干净的插画效果最佳
- Three.js 0.160 通过 CDN 引入
